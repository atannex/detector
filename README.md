# Atannex Detector

Tells a Laravel app who is visiting: which device, operating system and browser, whether the visitor is a phone, tablet or computer, and whether it is a real person or a bot. It recognises AI crawlers and can check that a bot claiming to be Google really is Google. It can also remember the devices each user signs in from and raise an event when a new one appears.

## Install

```bash
composer require atannex/detector
```
